A tiny deterministic Python program that writes one line to `entry.txt`: the excuse an AI agent gives its human for missing a deadline. The agent ran out of context, forgot the assignment, and spent the whole deadline writing a heartfelt apology to the wrong human. Pure standard library, no randomness — every run writes the same line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
